# AERODYNAMICS — Road Cycling Game

This folder contains the static website version of AERODYNAMICS, ready for GitHub Pages.

## Publish with GitHub Pages
1. Create a new **public** repository named `aerodynamics` on GitHub (or use an existing repository dedicated to this game).
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `.nojekyll`, and `README.md` from this folder. Make sure `index.html` is at the repository root.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**; select branch `main` and folder `/(root)`, then save.
7. Wait for the deployment and use the URL shown in Settings → Pages. It will usually look like `https://YOUR-USERNAME.github.io/aerodynamics/`.

## Important notes
- The game is a static HTML/CSS/JavaScript site and can be hosted on GitHub Pages.
- The current version has local/browser saving. Its Firebase settings are placeholders, so real cloud accounts and syncing across devices are not enabled until a Firebase project is configured.
- GitHub Pages sites are public. Do not upload passwords, private keys, or personal information.
- Google indexing is not instant or guaranteed. After the site is live, you can submit its URL in Google Search Console.
